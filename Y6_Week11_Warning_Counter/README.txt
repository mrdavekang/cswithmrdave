YEAR 6 WEEK 11 — WARNING COUNTER

A buildless, static HTML lesson for GitHub Pages. Open index.html directly or
serve this directory. No npm install, build service or account is needed.
MakeCode requires internet; actual code is made in that separate editor.

PEDAGOGY
Do Now: two shuffled code-reading MCQs and one supported short explanation.
Types of Learning: one visible KSU goal per page, with readiness/support choice.
Main Task 1: reopen the Week 10 counter and build a visitors >= 5 decision.
Main Task 2: repeat the warning three times, then show the total.
One practical checkpoint: 4, 5, 6 and B reset. No repeated written test diary.
Learning Pitstop follows Main Task 2 and gives a ready-made useful next action.
Extensions: meaningful simulator change, or supervised Grove LED / display /
gesture choices with actual blocks and manufacturer-reference wiring.
Plenary: one short supported explanation; an oral route is available.
Exit: one support choice, not a written improvement target.
Save & submit: PDF report + real MakeCode HEX to Teams; JSON kept for resuming.

ACCESS AND PROGRESS
Students type name and class, choose solo/pair and optional partner name.
Partner presence never locks progress; Continue alone retains earlier work.
English stays visible with optional Mandarin or Korean support alongside it.
Authentic English MakeCode block labels stay unchanged for editor matching.
The original school KSU and pitstop posters are reused unchanged.
Normal students follow a linear route and can revisit visited steps.
Type teacher as the name to preview any step; this is NOT authentication.
It never exposes another pupil's responses. There are no teacher passwords.
No strict keyword matching or requirement to get an MCQ right to proceed.
Help / skip remains available and is not recorded as practical success.

DATA / FILES
Responses, shuffled choice order and progress save to this browser's local
storage. Backup JSON can be loaded on the welcome page on another device.
Only this lesson's validated Week 11 backup format is accepted.
No Supabase project or class-tracking database is connected by this app.
Do not include private pupil backups or response exports in the public repo.
The PDF downloads directly using bundled jsPDF. Text is rendered locally to
page images so English, Mandarin and Korean keep their visible script. It is
not sent to an outside service. A text-based HTML print report remains available
through the browser's Print / Save as PDF function as a fallback.
The app cannot automatically inspect MakeCode, take a cross-origin screenshot
of student work or verify a Teams submission. The submitted HEX is the real
programming evidence; practical confirmations are explicitly self-reported.

GROVE SAFETY AND SOURCES
Hardware work requires teacher permission, a matching kit and checked power.
Power off before connecting. No school hardware has been physically tested
for these reference assets. The display drawing is a connection map, not a
photograph. The sensor is not an automatic people detector.
LED: Grove P0/P14 socket, code uses P0.
4-Digit Display: Grove P1/P15 socket; setup uses P1 and P15, not defaults.
Gesture: I2C socket and Grove event block; confirm direction on actual hardware.

# Coding Jam Day 1: Investigate and pitch

Open `index.html` in a browser or host it on any static website. The app has no server dependencies and does not collect or transmit student responses.

**60 minutes. Teams of 2–3.** Find out what gets in someone’s way, then pitch one useful interaction your team can realistically build.

Students can save a JSON backup, print or save their notes to PDF, and bring their notes into the next day's app. A backup carries planning notes only, not source code or Canva files. Browser autosave depends on the browser and device; students should export a backup before changing device.

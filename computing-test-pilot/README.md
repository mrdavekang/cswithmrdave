# Computing Test pilot

Pilot link:

https://mrdavekang.github.io/cswithmrdave/computing-test-pilot/?s=6d476074-0dd4-48b4-874e-ede95cc603f1

Choose a fictional name, arrange the steps, run or edit the sample Python program, and submit. This pilot only accepts the three sample names. Keep personal details out of answers.

## Review responses

In the Supabase project **cswithmrdave**, open **Table Editor → computing_test_responses** with your existing Supabase account. The row contains the sample name, final Python source, item order, written answer, server submission time, and receipt. Match `sitting_id` to `computing_test_sittings` for the class. In `computing_test_sittings`, switch `is_open` off to close the demo link.

## Configure a test

`test.js` contains the public question text, Python starter code and sample inputs, and drag-and-drop items. Its question IDs become keys in the saved answers. For a new assessment, create a new test key and class sitting. The included migration deliberately limits the pilot to its sample sitting and aliases. Before using it with a real class, configure the actual assessment, class, and how students identify themselves. Students can use a class link without school sign-in.

The browser uses a Supabase publishable key. Supabase grants anonymous visitors permission to find an open sitting and to submit to the pilot. Submission rows have no public read, edit, or delete access. Do not add answer keys, student names, school rosters, or Supabase secret keys to this public repository.

11:20 Starter (6 min); 11:26 Types of Learning (2 min); 11:28 brief model (2 min); 11:30 Main 1 (15 min); 11:45 Main 2 (20 min); 12:05 response window (2 min) and about 3 min teacher-paced discussion; 12:10 follow-up/extension (3 min); 12:13 Pit Stop (3 min); 12:16 plenary and saving (4 min).

Protected planning window: 11:30–11:45. Main 1 does not arm an automatic discussion. Leave the instructions projected. Students follow the model and attempt booklet Questions 1–3 independently. Written help requests are saved but are not guaranteed instant alerts.

Individual check-ins: 11:45–11:50, 11:50–11:55, 11:55–12:00 and 12:00–12:05. Ask each student to show one trace row and explain one decision. A written response or thinking pause is fine. Other students continue Main 2.

Change the class view?

Which control do I need?

I want to read students’ work.
Use Student work. Select a student card to read answers and code. This is private and does not move the class.
I want to change the board instructions.
Choose a stage in Board and lesson timer, then select Show. Selecting the stage alone changes nothing. Students keep their own lesson pages.
I want students to answer a question.
Choose the question and response time in Run a discussion, then Start discussion. Send invitation again reminds them without resetting their answers.
I want to discuss the answer.
Close responses stops submissions. Unless manual reveal is checked, the answer appears for students. Discussion answers is where you read replies and award points.
I want students to continue their work.
Return class to independent work removes the discussion notice. It does not erase responses or house points.
I want to show something publicly.
Open projector window and share that window only. The private dashboard contains names, drafts and saved work.

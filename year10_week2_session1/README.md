# Week 2 Session 1 - Choosing Data Types

Static, self-contained lesson app for Year 10 OxfordAQA International GCSE Computer Science (9210).

## Use

1. Open `index.html` in a modern browser, or upload this folder to GitHub Pages.
2. Students enter their name and class.
3. Enter `teacher` as the name to activate teacher preview mode; class may be blank.
4. Student responses autosave on the current device.
5. Evidence images are stored locally in the browser.
6. The export button builds a complete print report. Select **Save as PDF** in the browser print window.

Python code is displayed for copying, but it is not executed by the website. Students run all code in their own Python IDE.

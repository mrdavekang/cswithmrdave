Textbook reading · AO1

What is a data type?

Read carefully before Main Activity 1. The examination vocabulary and Python vocabulary are not always identical.

OxfordAQA Student BookPrinted page 16PDF page 20Specification 3.2.1

Student reading

Programs work with values, and values can be stored in variables. A computer needs to know what kind of value it is storing because different kinds of data are represented and processed differently. The category assigned to a value is its data type.

IntegerWhole number without a decimal point.
6 · -12 · 250
RealNumber with a decimal point. Python calls it float.
6.0 · 19.99
StringOne or more characters inside quotes.
"Aisha" · "6"
BooleanOne of two logical values.
True · False
CharacterOne text symbol. Python stores it as a one-character str.
"A" · "?"
Exam-to-Python translationOxfordAQA real = Python float. OxfordAQA character = Python str containing one character.

Before you start: understand the three answers

For every scenario, you will provide three separate pieces of information. They are related, but they are not the same.

1. Specification termThe examination word used by OxfordAQA: integer, real, Boolean, character or string.
2. Python typeThe label Python would display using type(): int, float, bool or str.
3. JustificationA sentence explaining what the value represents and why that type is suitable.
Why are there two sets of names?OxfordAQA tests general computer-science vocabulary that works across programming languages. Python uses its own shorter, language-specific type names. For example, OxfordAQA says real, while Python reports float.

Follow these four steps

  1. Look at the value. Check for quotation marks, a decimal point, or the literals True/False.
  2. Choose the OxfordAQA term. Select integer, real, Boolean, character or string.
  3. Translate it into Python vocabulary. Select int, float, bool or str.
  4. Justify the choice. Explain what the value represents and whether it needs arithmetic, decimal precision, text, or a yes/no state.

How Python chooses a type

Python normally chooses a type when a value is assigned. Whole-number literals become int; decimal literals become float; quoted values become str; and True or False become bool.

  • Adding, subtracting or multiplying integers normally produces an integer.
  • If a calculation includes a float, the result is normally a float.
  • Ordinary division / produces a float.
  • input() initially produces a string, even when the user types digits.
Scope boundaryObserve the input-string problem today. You will learn type conversion in the later planned session.

Worked example A: assigned values

score = 36
average_score = 36.0
student_name = "Aisha"
completed = True
grade_code = "B"

print(type(score))
print(type(average_score))
print(type(student_name))
print(type(completed))
print(type(grade_code))

Worked example B: calculated values

print(36, type(36))
print(36.0, type(36.0))
print(36 * 10, type(36 * 10))
print(36 + 1.0, type(36 + 1.0))
print(36 / 6, type(36 / 6))

Worked example C: the input surprise

age = input("Enter your age: ")
print(age)
print(type(age))

YEAR 11 COMPUTER SCIENCE - WEEK 2 MERGED NETWORKS LESSON

PURPOSE
This static GitHub Pages-ready app merges the former Week 2 Session 1 and Session 2 network lessons into one 60-minute lesson. It covers OxfordAQA specification 3.5 foundations: network definition, benefits and risks, LAN/WAN, wired/wireless, and copper/fibre suitability.

FILES
- index.html: student lesson and teacher review
- worksheet.html: printable two-page A4 paper worksheet
- styles.css: responsive and print styling
- app.js: navigation, local saving, checking, image upload and PDF export
- assets/: Raleway font, three teaching images, and the unchanged November 2025 examination page
- resources/: complete November 2025 Paper 2 question paper
- vendor/: local jsPDF library

STUDENT USE
1. Open index.html through GitHub Pages.
2. Enter a name and class.
3. Open and print worksheet.html if paper copies were not already provided.
4. Complete each core stage in sequence.
5. Upload at least one photograph of the completed paper task.
6. Download the final PDF and submit it in Teams.

TEACHER REVIEW
Teacher mode is deliberately not displayed on the landing page.
- Enter teacher as the name. The class field may be left blank.
- Or add ?mode=teacher-review to the page URL.
Teacher review opens every lesson page and displays teacher guidance.

DATA AND PRIVACY
Student responses and compressed image evidence are stored only in the current browser using localStorage. No server or external database is required. Students should download the PDF before changing browser/device or clearing browser data.

GITHUB PAGES
Upload the complete folder without changing its internal structure. Set GitHub Pages to publish from the branch/folder containing index.html. All links and assets use relative paths.

ASSESSMENT NOTE
The app records activity completion and submitted evidence. It does not claim that completion equals mastery. The teacher should assess the accuracy and quality of the paper design, classification evidence and plenary responses.

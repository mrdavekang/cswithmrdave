HOW TO USE LOCALLY
1. Open index.html in a modern browser.
2. Students enter their name and class.
3. Their work saves in that browser on that device.
4. Students export one PDF from the final page and submit it to Teams.

TEACHER REVIEW
Enter teacher in the name field. The class field may be left empty.
All lesson sections will open on one continuous review page.
There is no visible teacher-mode button for students.

GITHUB PAGES
1. Upload the contents of this folder to the root of a GitHub repository.
2. In the repository settings, enable GitHub Pages from the main branch and root folder.
3. Keep the assets, resources and vendor folders in their existing locations.

STUDENT RESOURCES INCLUDED

LESSON SEQUENCE
1. Resource and workspace check
2. Original Questions 01.1-01.3 navigation Starter
3. Learning Pit Stop 1: knowledge, skills or understanding
4. Teacher-created trace clinic using the rleImage algorithm
5. Original Questions 03.1-03.2 trace task
6. Requirements-to-code clinic for Question 08
7. Original Questions 08.1-08.2 modification, testing and evidence task
8. Learning Pit Stop 2: new learning, consolidating, treading water or drowning
9. Optional extension route
10. AO3 plenary, PDF export and Teams submission

LEARNING AND EVIDENCE FEATURES
- Original past-paper wording presented as images captured from the supplied paper
- Clear labels separating original questions from teacher-created scaffolds
- Required evidence-line references in the navigation Starter
- Event-based trace modelling followed by an expandable, editable trace table
- Requirement, location, operation and evidence planning before programming
- Complete source-code entry and prescribed test record for Question 08
- One required and one optional image-evidence slot for the main Section B task
- Consolidation and deep-challenge extension routes
- Evidence-based Learning Pit Stops with actionable next-step guidance
- Image selection, drag and drop, or clipboard paste
- Local autosave and a multi-page PDF learning record

PRIVACY
The app has no server or student database. Responses remain in the browser's local storage until cleared.

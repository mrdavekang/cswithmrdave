YEAR 11 COMPUTER SCIENCE - NOVEMBER 2024 PAPER 1 SKILLS LAB

HOW TO USE LOCALLY
1. Open index.html in a modern browser.
2. Students enter their name and class.
3. Their work saves in that browser on that device.
4. Students export one PDF from the final page and submit it to Teams.

TEACHER REVIEW
Enter teacher in the name field. The class field may be left empty.
All lesson sections will open on one continuous review page.
There is no visible teacher-mode button for students.

GITHUB PAGES
1. Upload the contents of this folder to the root of a GitHub repository.
2. In the repository settings, enable GitHub Pages from the main branch and root folder.
3. Keep the assets, resources and vendor folders in their existing locations.

STUDENT RESOURCES INCLUDED
- November 2024 Preliminary Material PDF
- November 2024 Question Paper PDF
- Python skeleton program
- pattern.txt
- 0.txt (also supplied as zero.txt for the official examination filename)
- 1.txt (also supplied as one.txt for the official examination filename)

The Resources page appears before the Starter so students can identify and download the complete examination package first.

The mark scheme is deliberately not included.

EVIDENCE FEATURES
- Section A typed responses
- Expandable, directly editable trace table
- Complete source-code entry for Question 08 and the optional Question 04
- Two image-evidence slots for each Section B task
- Image selection, drag and drop, or clipboard paste
- Local autosave and PDF export

PRIVACY
The app has no server or student database. Responses remain in the browser's local storage until cleared.

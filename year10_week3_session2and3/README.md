# Year 10 OxfordAQA 9210 · Term 1 Week 3 · Combined Sessions 2 and 3

## Lesson focus
Represent, trace and implement an algorithm in a single 60-minute lesson.

## Required route
1. Read First · 00-04
2. Do Now · 04-08
3. Types of Learning · 08-11
4. Main Task 1 · 11-27
5. Main Task 2 · 27-49
6. Extension · 49-52
7. Learning Pit Stop · 52-55
8. Plenary · 55-60

## How to use
Open `index.html` in a modern browser. The app is static and makes no network requests.

- Students enter name and class.
- Enter `teacher` as the name for teacher preview.
- Text responses are stored in browser local storage.
- IDE screenshots are stored locally using IndexedDB when the browser permits it.
- Python does not run in the browser. Students use their normal Python IDE.
- Review / export builds an evidence report and uses the browser print dialog. Choose Save as PDF.

## Scope
The lesson is restricted to the relevant Year 10 OxfordAQA 9210 content: sequence, flowcharts, pseudocode, assignment and reassignment, trace tables, input/output, number conversion and translation to familiar Python. Selection, loops, arrays, subroutines and validation are not introduced as core content.

## Source focus
- OxfordAQA International GCSE Computer Science (9210): 3.1.1, 3.2.2, 3.2.7 and 3.2.8.
- OxfordAQA Student Book: flowcharts and pseudocode, conversion of input data, and trace tables.
- Supplied Paper 2 material informs the optional exam-style extension.

No font files are included. The CSS requests Raleway if it is already installed on the device, with standard sans-serif fallbacks.

# Week 1 Session 3 - From Algorithms to Programs

This is a single-file static lesson app for OxfordAQA International GCSE Computer Science 9210.

## Open locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the root of the repository.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the root folder, then save.

## Teacher preview

Enter `teacher` as the name. The class may be left blank. Teacher preview allows free navigation and includes a button to populate sample answers.

## Student records and evidence

- Text answers are autosaved in the browser on the student's device.
- Evidence images are stored in that browser using IndexedDB.
- The PDF report includes every saved answer, pasted program and evidence image.
- Students should export the report, open it to check it, and submit it through Microsoft Teams.

Because this is a static site with no server or student sign-in, teachers cannot retrieve student records centrally. Microsoft Teams PDF submission is the collection method.

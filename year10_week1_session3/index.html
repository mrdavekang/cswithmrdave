Algorithms and programs

Textbook: printed page 10Digital PDF: page 14 of 317Approx. 3 minutes

An algorithm is an ordered set of steps used to solve a problem or complete a task. In Computer Science, an algorithm describes the logical actions a program should perform. It can show what data is entered as input, how the data is processed, and what information is produced as output.

An algorithm describes a solution, but it is not a working computer program. It cannot be run directly because it is not written in a particular programming language.

A program is an implementation of an algorithm. It translates the planned steps into instructions written in a programming language such as Python. Programmers plan with algorithms so they can check their logic, find missing steps, communicate the solution and keep a record before coding.

The same clear algorithm could be implemented in Python, Java or another suitable language.

Introduction to pseudocode

Textbook: printed pages 12–13Digital PDF: pages 16–17 of 317Approx. 4 minutes

Pseudocode represents an algorithm using structured, readable instructions. It looks similar to program code, but it is not written in a programming language and cannot be run on a computer. It helps programmers focus on the logic before writing the real program.

The assignment arrow points from a value towards the variable that will store it. For example, Score ← 20 assigns the value 20 to Score. In Python, this would be written score = 20.

USERINPUT represents data entered by the user. Name ← USERINPUT stores the user’s entry in Name. A processing statement such as Total ← CorrectAnswers * 5 performs a calculation. The command OUTPUT displays a value or message.

Today’s learning

WAGBA

We are getting better at organising digital work and explaining how an input makes a program produce an output.

Knowledge
Programs follow ordered instructions. Coordinates describe a sprite’s position: x changes left/right and y changes down/up.
Skills
Organise files, predict code, build and test a Scratch script, debug it, and explain one purposeful change.
Understanding
Clear routines make work easier to find. Testing helps us compare our prediction with what really happens.

Success checks

  • I can use Start–Work–Finish routines.
  • I can choose a sensible folder and filename.
  • I can identify an input and output.
  • I can predict, test, modify and explain Scratch code.

Challenge: Can you explain why changing the sign or axis changes the sprite’s direction?

Today's Learning

Key Topic: Year 6 Computing routines, digital organisation and programming recall

WAGBA: We are getting better at working independently in the Computing Lab and explaining how a program responds to inputs.

Knowledge: A program follows an ordered sequence of instructions and uses inputs to produce outputs.

Skills: Organise and save digital work correctly, run and modify a Scratch program, and capture evidence of what was changed.

Understanding: Good routines and organised evidence help us work safely, protect our work and improve our programs.

Keywords: algorithm, sequence, program, input, process, output, file, folder, evidence, test, debug

Challenge: Can you explain exactly how an input causes an output and improve the program without breaking it?

Success criteria

  • I can explain and follow the Computing Lab routines.
  • I can create the correct folder and use the agreed filename.
  • I can identify an input and an output in a Scratch program.
  • I can make, test and explain one purposeful change.
  • I can complete an honest confidence reflection.

0:00–0:35 · One character, three expressions
VISUAL: Open the teacher preview at Main Task 1. Crop to the Garden Guide preview and frame strip. Click Play preview and let it loop twice. Freeze on Surprised. Cut to the actual Mission WAGBA.
ANNOTATIONS: “Calm → Surprised → Happy” · “Same body. New face.” · “WAGBA”
NARRATION: Watch this little Garden Guide. Calm, surprised, happy… and back to calm. Did you see the body move? No. Only the expression changed. The computer is showing three still pictures, one after another, and it looks like one character reacting. In theory, you made a pixel character people could recognise at game size. Today you’ll use that same idea to make it react. Our WAGBA is: we are getting better at creating consistent sprite frames and using a program to play them in order.

0:35–1:12 · The arcade connection
VISUAL: Zoom into the Arcade Archive cards. Show the credited photo of Toru Iwatani, then pan across to Shigeo Funaki’s movement-rule illustration. Do not present the diagram as a photograph or game screenshot. Pan down to the app’s original Garden Guide stills.
ANNOTATIONS: “Toru Iwatani · game design” · “Shigeo Funaki · programming” · “Design the frames. Code the change.”
NARRATION: Here’s the arcade connection. On the original Pac-Man team, Toru Iwatani planned and designed the game, and Shigeo Funaki worked on the programming. Think about the difference: someone designs what the character looks like; someone writes the code that makes the game show the right thing at the right time. You’ll try both jobs today. And remember your theory work: a small grid doesn’t give you many pixels. A few well-placed squares can tell a player much more than a crowded drawing.

1:53–3:08 · Build the three boards
VISUAL: In Main Task 1A, animate a ring over Duplicate frame, Select Face layer, then two pixel buttons. Cut to the blank board in Main Task 1B. Draw or import a different, original sprite. Zoom to the selected layer, Pencil or Eraser, the changed pixels and frame name. Show the whole strip before playing.
ANNOTATIONS: “Practise safely” · “Duplicate frame” · “Select Face” · “Edit just 2 pixels” · “Make 3 distinct frames”
NARRATION: Start with Main Task One A. Duplicate Garden Guide, select Face, change two mouth pixels, and play it. Now leave the sample behind. In Main Task One B, draw your own sprite or import the character you made in theory. Your JSON keeps your layers. The board strip holds complete pictures; the Face and Body layers are parts of whichever board you’ve selected. Give your sprite a simple body and a recognisable detail. Duplicate its first board. On the copy, select Face, choose Pencil or Eraser, and change the mouth or eyes. Keep the body in place. Name this new expression, then duplicate again for a third one. Maybe your character looks worried, or maybe it’s trying not to laugh. That’s up to you. Watch all three boards in order. If the whole sprite jumps, go back and align the body. Let the preview play a full cycle before you move on.

3:08–4:15 · Make the program play it
VISUAL: In Loop model show both speeds, then the Main Task 2 route buttons. For Scratch, crop to the annotated Costumes upload image and the block stack. For Python, zoom to delay in the editable code, then Run Python and preview. Show the same boards at both delays.
ANNOTATIONS: “Choose one route” · “One sprite, several costumes” · “0.4 s → 0.8 s” · “Same order. Slower.”
NARRATION: Now you’ll make a program play those pictures. Try the two speeds in the Loop Model, then choose one route. In Scratch, download the individual frame pictures. Upload them as costumes on one sprite, in board order. Follow the annotated steps: start on your first costume, then put wait and next costume inside forever. Run it and change the wait. Save the Scratch project and use the file check. If you choose browser Python, your boards are already there. Click Run Python. Now change the delay from zero point four to zero point eight and run again. The same frames stay in the same order, but each one stays on screen twice as long. Write down what changed in your test.

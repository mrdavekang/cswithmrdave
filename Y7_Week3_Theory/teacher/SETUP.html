Teacher setup & answer key

One 60-minute theory lesson, followed by optional question practice after submission.

Before sharing with students

The app is complete as a local/static lesson. It is not connected to Teams or Gimkit. The submission pictures are labelled visual walkthroughs, not screenshots captured on your school's devices.

1. Open and configure

Extract the entire ZIP. Open index.html, enter teacher as the name and open Teacher tools. For tablets and managed devices, host the complete folder and share its URL. No build or installation is required.

Enter the exact Teams assignment title, its optional direct URL and the Gimkit Assignment or Practice link. Save locally, then Export config.js and replace the deployed config.js file. Local teacher settings do not automatically sync to students. The configured-link tool carries only the title and links, not screenshot images.

2. Gimkit: 15 questions

Download the Template 1 CSV. In Gimkit, create a kit, choose Import from Spreadsheet, and upload the CSV. It includes the template title row, five headers, and 15 question rows. Preview every question after importing, especially the multi-line code in questions 13 and 14.

The bank has one correct answer and three distractors per question. Share the resulting Assignment or Practice link, not a kit-view page exposing answers. A Gimkit Assignment requires the appropriate account access; the independent Practice route is an alternative. Check your account's current options. Gameplay may repeat questions: 15 unique questions is not automatically a fixed test out of 15.

The optional quiz inside this app is a backup for when Gimkit is unavailable. It is not an extra compulsory activity and creates no second submission.

3. Genuine device screenshots

Capture a test student's screens on the school devices. Hide names, account details, notifications and unrelated documents. In Teacher tools, select the device, browser, Teams app/browser route and one of the nine guide steps. Upload PNG, JPEG or WebP, then tap the picture to place a numbered highlight. Add a short caption noting the platform/version. Export config.js again.

Each route has separate slots. An iPad screenshot is not reused for Android or Windows. The app does not mislabel the default illustrations as authentic screenshots.

5. Assessment and support

Most tasks record an attempted answer, not require a correct one to progress. “I am not sure yet” is a valid formative response. First responses remain visible after corrections. The independent checkpoint keeps its original predictions. Its Python workspace unlocks only after that first submission, allowing students to test and record later corrections without overwriting their first answers.

For a learner who cannot complete the whole core, open their profile and choose Teacher: release incomplete evidence. Enter teacher and the reason. This permits progress/export without filling missing answers or changing their identity. The report records the release and the missing responses. It is a convenience control, not secure authentication.

“I need help” records a request locally and tells the student to raise a hand. It does not send you a notification. Oral explanation checkboxes report that the student spoke; the app does not record or assess the speech.

7. Gimkit / backup question key

1. Which line correctly moves the Turtle to (60, 20)?

Correct: t.goto(60, 20)

Use brackets around the values and a comma between x and y.

2. Which position does t.goto(-30, 50) specify?

Correct: (-30, 50)

The first value is x. The second is y. Keep the negative sign.

3. What does 40 mean in t.forward(40)?

Correct: The distance to move forwards

forward() accepts a distance, not a turning angle or absolute position.

4. What does t.penup() allow the Turtle to do?

Correct: Move without drawing a line

Pen up stops drawing, not movement.

5. What is the purpose of this line?

# Draw the route to the classroom

Correct: Leave a note for someone reading the code

A Python comment explains code to people. It is not executed as a Turtle command.

6. The Turtle is at (20, 10), facing up. It runs t.right(90). Which statement is correct?

Correct: At (20, 10), facing right

The Turtle turns on the spot. Turning changes its heading, not its position.

7. The Turtle faces right. It runs t.left(90). Which way does it face now?

Correct: Up

A 90-degree left turn from right is a quarter-turn anticlockwise towards up.

8. Start at (10, 20), facing right. After t.forward(30), where does the Turtle finish?

Correct: (40, 20)

Add 30 to x: 10 + 30 = 40. The y-coordinate stays 20.

9. The Turtle is already at (-20, 30). It runs t.goto(-20, 30) again. Where does it finish?

Correct: (-20, 30)

goto() names a destination. The Turtle is already at that destination, so it does not move.

10. Which comment best explains this code?

t.penup()
t.goto(-60, 0)
t.pendown()

Correct: # Move without drawing, then lower the pen

The pen is raised for the move, then lowered ready for the next drawing instruction.

11. Start at (0, 0), facing right, pen down. Where does this program finish?

t.forward(60)
t.right(90)
t.forward(20)

Correct: (60, -20)

Move right 60, turn down, then move down 20. The endpoint is (60, -20).

12. Start at (0, 0), facing right, pen down. Where does this program finish?

t.goto(0, 40)
t.forward(20)

Correct: (20, 40)

goto() changes position without changing heading. The Turtle still faces right, so forward(20) adds 20 to x.

13. Start at (0, 0) on a blank drawing. Which line does this code draw?

t.penup()
t.goto(40, 0)
t.pendown()
t.goto(40, 30)

Correct: Only (40, 0) to (40, 30)

The first move is pen up. Only the move after pendown() leaves a line.

14. Both start at (0, 0), facing right, pen down. Which statement is correct?

# Program A
t.forward(40)
t.right(90)

# Program B
t.right(90)
t.forward(40)

Correct: Different final positions, same final direction

A ends at (40, 0), and B at (0, -40). Both finish facing down. The order changes the route.

15. Start at (0, 0), facing right, pen down. The target is (0, 30). Which single change makes this code reach it?

t.right(90)
t.forward(30)

Correct: Replace t.right(90) with t.left(90)

The route must go up. Turning left 90 degrees from right faces up, then forward(30) reaches (0, 30).

8. Official references and boundaries

The question workspaces now execute Python using a bundled Skulpt interpreter and a classroom Turtle adapter. They are not limited to parsing numeric commands: variables, calculations, conditions, loops, functions and print() execute as Python. The adapter supports the lesson commands and a documented drawing subset, not all desktop CPython/Tkinter features. Comments do not move the Turtle; goto() does not change heading; turns do not change position. No loops are required in this session. See the Python IDE guide for controls, limits and the prediction/assessment workflow.

Student work is local. The PDF has no automatically verified Teams status. Hosted initial access, Teams, Gimkit and official source links need internet access. Device policies may affect downloads, sharing and browser storage.

Read: Computer Science and digital creativity

Digital creativity uses digital tools to communicate ideas or create media, such as presentations, images or videos.

Human Robot: Precise Algorithms

Not complete
1

Read: Algorithm, command and sequence

AlgorithmAn ordered set of precise instructions for completing a task or solving a problem.
CommandOne instruction that the computer or robot can carry out.
SequenceThe order in which the commands are followed.

A computer cannot guess what you meant. “Go over there” is unclear. “Move forward one square” is precise and testable.

    Algorithms and sequencing

    In an algorithm, each step must happen at a sensible time. If a step is missing or placed too early, the result may be incorrect.

    Worked example: To open a saved document: 1. Open the folder → 2. Find the file → 3. Double-click the file. Opening the folder must happen first.

    Your task: Give each sandwich instruction a different position from 1 to 5.

    B

    Scratch: Read and predict

    Scratch represents commands as coloured blocks. The green flag starts this program. The blocks inside repeat 4 run four times. Read every block before predicting the output.

    C

    Input, Process and Output

    A digital system can be described using three connected stages:

    InputInformation or an action that enters the system.
    ProcessWhat the system does with the input.
    OutputThe result produced by the system.

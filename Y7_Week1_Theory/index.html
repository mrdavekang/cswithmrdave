WAGBA

Explain how precise instructions form an algorithm and demonstrate the safe, organised and independent working routines expected in KS3 Computer Science.

Knowledge

  • An algorithm is an ordered set of instructions.
  • Sequence affects the output.
  • Systems can be described as input, process and output.

Skills

  • Arrange and trace instructions.
  • Test and debug an algorithm.
  • Respond safely and responsibly.

Understanding

  • Computers follow instructions exactly.
  • Errors are useful evidence for improvement.
  • Safe, organised habits support successful learning.

Keywords

algorithm · sequence · command · program · input · process · output · evidence · debugging

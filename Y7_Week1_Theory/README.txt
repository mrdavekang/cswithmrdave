YEAR 7 WEEK 1 THEORY WEB APP
Thinking Like a Computer Scientist

FILES
- index.html: open this file to run the app
- styles.css and app.js: interface and interaction logic
- assets/: lesson images used by the task configuration

HOSTING
1. Extract the ZIP without changing the folder structure.
2. Upload the full folder to your chosen static host.
3. Set index.html as the home page.
4. No server-side database or external JavaScript library is required.

STUDENT WORKFLOW
- Students enter their name and class.
- Progress is saved locally in the browser on that device.
- Core sections must be attempted before PDF export is enabled.
- The optional extension appears in the PDF only when attempted.
- Students upload the PDF to the Microsoft Teams Assignment named: Week 1 Theory.

INVISIBLE TEACHER TEST MODE
- No teacher checkbox, control button or test panel is shown in the student interface.
- To open a separate teacher testing session, add ?teacher=1 to the hosted URL, for example:
  https://your-site.example/index.html?teacher=1
- This hidden test mode unlocks every section and uses separate local storage from student work.
- Remove ?teacher=1 before sharing the link with students.

PDF EXPORT
- The PDF is generated inside the browser without sending responses to an external service.
- The downloaded filename follows this pattern:
  CLASS_STUDENTNAME_Week_1_Theory.pdf

PRIVACY AND DEVICE NOTE
- Responses are stored only in that browser's local storage until it is cleared.
- On shared devices, students should use the Change learner button and verify their own name before continuing.
- Do not ask students to enter passwords, addresses, phone numbers or other private information.

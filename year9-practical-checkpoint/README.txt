Year 9 Practical Checkpoint - Two separate programs

Open index.html or serve this complete folder on a local static server.
Python runs using the bundled local Skulpt Python 3 subset. Keep vendor,
editor-core.js, python-runtime.js and python-worker.js with the app.

Indent/Dedent and Undo/Redo support keyboard and touch editing.
input() questions appear one at a time in the Console, with Enter or Send.

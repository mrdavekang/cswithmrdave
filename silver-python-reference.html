How to use this guide

Silver questions are wrapped in dramatic stories, but each is really a well-known type of problem. This guide has two halves:

  1. Topic library — tutorial-style explanations of the tools Silver needs, with generic example syntax. The examples are not solutions to the questions.
  2. Hint map — each question is stripped back to its plain task, with a list of the topics most likely to help. Click a pill to jump to the explanation.
Rules reminder: you may read this reference, but all code must be your own. No AI tools allowed. This page tells you what techniques exist; choosing and combining them is up to you.

Tip: when a problem mentions a grid / maze, think searching (flood fill or BFS). When it mentions nodes and one-way connections, think graphs. When it mentions a window / consecutive run, think sliding window.

String cleaning & analysis

Often you must strip a string down to just letters before analysing it.

s = "T-minus 5 minutes!"
clean = ""
for ch in s:
    if ch.isalpha():        # keep letters only
        clean += ch.lower()  # and make lowercase
# useful checks:
ch.isalpha()  # True if a letter
ch.isdigit()  # True if 0-9
ch.isspace()  # True if a space/tab

Letters as numbers — ord() and chr()

Every character has a number code. ord() turns a letter into its code, chr() turns a code back into a letter. This is the key to cipher problems.

ord("A")          # 65
ord("a")          # 97
chr(66)           # 'B'

# turn a capital letter into 0-25 ("position in the alphabet")
pos = ord("C") - ord("A")   # 2
# turn 0-25 back into a capital letter
letter = chr(pos + ord("A"))
If a question numbers letters A=1…Z=26, you can build that with ord(ch) - ord("A") + 1.

Wrap-around with modulo

When something cycles (A after Z, or repeating a short key), % keeps numbers in range.

26 % 26   # 0   (Z wraps back to A)
-1 % 26   # 25  (Python wraps negatives upward — handy for shifting backwards)

# cycle through a short list of keys forever
keys = [5, 1, 9]
for i in range(20):
    k = keys[i % len(keys)]   # 5,1,9,5,1,9,...
i % len(keys) is the standard way to repeat a short key across a long message.

Counting items — dictionary / Counter

tally = {}
for ch in text:
    tally[ch] = tally.get(ch, 0) + 1
# most common value and how often it appears:
best = max(tally, key=tally.get)
how_many = tally[best]

# the easy way, with the standard library:
from collections import Counter
c = Counter(text)
c.most_common(1)   # [(letter, count)] of the top item

2D grids (nested lists)

A grid is a list of rows; each row is a list. You reach a cell with two indexes: grid[row][col].

grid = [
  [30, 70, 40],
  [10, 20, 90],
]
rows = len(grid)        # 2
cols = len(grid[0])     # 3
grid[1][2]              # 90

for r in range(rows):
    for c in range(cols):
        value = grid[r][c]

# the 4 neighbours (up/down/left/right):
for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
    nr, nc = r + dr, c + dc
    if 0 <= nr < rows and 0 <= nc < cols:   # stay inside the grid
        neighbour = grid[nr][nc]
For 8 directions (diagonals too) add (-1,-1),(-1,1),(1,-1),(1,1) to the list of moves.

Recursion

A function that calls itself. Needs a base case to stop. Useful for exploring branching paths.

def countdown(n):
    if n == 0:        # base case — stop
        return
    print(n)
    countdown(n - 1)  # recursive step
Deep recursion can hit Python's limit. For very large grids, the loop-based BFS below is often safer than deep recursion.

Flood fill — measuring connected regions

"Largest connected area" problems are flood fill: pick a starting cell, then spread out to every connected neighbour that also qualifies, marking cells as visited so you don't count them twice.

# generic shape of a flood fill (using a stack)
visited = set()
def region_size(start_r, start_c):
    stack = [(start_r, start_c)]
    size = 0
    while stack:
        r, c = stack.pop()
        if (r, c) in visited:
            continue
        visited.add((r, c))
        size += 1
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r + dr, c + dc
            # if (nr,nc) is inside the grid AND still qualifies AND not visited:
            #     stack.append((nr, nc))
    return size
To find the largest region: loop over every cell, and whenever you find a qualifying cell that hasn't been visited, run a flood fill from it and remember the biggest size you've seen.

BFS — fewest moves / shortest path

"Minimum number of moves to get from A to B" on a grid is Breadth-First Search. It explores everything 1 move away, then 2 moves away, and so on — so the first time it reaches the target, that's the fewest moves.

from collections import deque
def shortest(start, is_goal, neighbours):
    queue = deque([(start, 0)])    # (cell, moves so far)
    seen = {start}
    while queue:
        cell, dist = queue.popleft()
        if is_goal(cell):
            return dist
        for nxt in neighbours(cell):   # valid moves from this cell
            if nxt not in seen:
                seen.add(nxt)
                queue.append((nxt, dist + 1))
    return -1   # never reached the goal
BFS works for 4-direction grids, 8-direction (king) moves, and mazes with special rules (e.g. a portal is just an extra "neighbour" you can move to). If a move shouldn't cost anything, don't add 1 to dist for it.

Graphs & adjacency lists

A graph is nodes joined by edges. A directed edge a b means you can go a→b but not back. Store connections in a dictionary:

edges = [("hi","asdf"), ("asdf","qwer"), ("qwer","bye")]
graph = {}
for a, b in edges:
    graph.setdefault(a, []).append(b)   # a -> [list of places you can reach]

# visit everything reachable from a start node (DFS):
def reachable(start):
    seen = set()
    stack = [start]
    while stack:
        node = stack.pop()
        if node in seen:
            continue
        seen.add(node)
        for nxt in graph.get(node, []):
            stack.append(nxt)
    return seen   # every node you can get to
"Which start node reaches every node?" → for a candidate start, run the traversal and check whether len(reachable(start)) == total number of nodes.

Sliding window

For "longest run that satisfies a rule" problems, slide a window with two pointers (left/right) and grow or shrink it.

left = 0
best = 0
# right end sweeps across the data
for right in range(len(data)):
    # ... update some count for data[right] ...
    while window_is_invalid():     # e.g. too many flips used
        # ... undo data[left] ...
        left += 1
    best = max(best, right - left + 1)
Classic use: "longest run of 1s if you may flip at most n zeros." The window is valid while the number of zeros inside it is ≤ n.

Running sums & resets

For "largest consecutive sum, but a special value resets it":

current = 0
best = 0
for x in values:
    if x == -1:        # the reset marker
        current = 0
    else:
        current += x
        best = max(best, current)
You can also track where the best run started/ended by remembering the index when current becomes a new best.

Permutations (itertools)

To list every ordering of some items, use the standard library. Sorting the results gives lexicographic (dictionary) order.

from itertools import permutations
for p in sorted(permutations([5, 6, 7])):
    print(p)
# (5,6,7) (5,7,6) (6,5,7) (6,7,5) (7,5,6) (7,6,5)
# permutations of a sorted input already come out in lexicographic order

Reading multi-line input

Several Silver problems give numbers on one line and a grid/string on the next. You can read lines and split them.

line = "4 3"
n, m = line.split()        # ['4', '3']
n, m = int(n), int(m)

keys = "5 1 9".split()              # ['5','1','9']
keys = [int(k) for k in keys]       # [5, 1, 9]

# a grid given as rows of characters
grid = [list(row) for row in ["..*", "..*"]]

# Sources and attribution

## Curriculum and teaching design

- School Year 8 Scheme of Learning, Term 1 Week 7: iteration, counters, infinite-loop avoidance and consolidation. The module/week title may need adjusting to actual class progress after assessment and holidays.
- [Teach Computing: Introduction to Python programming](https://teachcomputing.org/curriculum/key-stage-3/introduction-to-python-programming)
- [Raspberry Pi Foundation: Year 8 Round and round](https://www.raspberrypi.org/curriculum/archived/key-stage-3/introduction-to-python-programming/round-and-round)
- [NCCE computing pedagogy](https://teachcomputing.org/pedagogy): programme comprehension, modelling, PRIMM and contextual examples.
- [University of Helsinki Python MOOC: Simple loops](https://programming-26.mooc.fi/part-2/4-simple-loops/)
- [University of Helsinki Python MOOC: Loops with conditions](https://programming-26.mooc.fi/part-3/1-loops-with-conditions/)
- [OxfordAQA 9210 specification](https://www.oxfordaqa.com/wp-content/uploads/2025/02/oxfordaqa-gcse-computer-science-specification.pdf): iteration, variable updates and interpretation/implementation foundations.

The spacecraft challenges and mini-games are original classroom activities. “Helsinki-inspired” describes the exercise structure (requirements, examples, tests, increasing independence), not affiliation or reproduction of its course. The drawings are original SVGs with a playful space-crew aesthetic, not Among Us game assets.

## Runtime and libraries

- [Python IDLE](https://docs.python.org/3/library/idle.html): reference for editor/shell separation, indentation, running, interruption and variable inspection.
- [Pyodide](https://pyodide.org/): local unmodified runtime files reused from an existing project dependency bundle; MPL-2.0 license in `vendor/python/Pyodide-MPL-2.0.txt`. Source distribution: https://github.com/pyodide/pyodide. The runtime includes Python under its own license; Python license texts are available in the bundled standard library (the `LICENSE.txt` file) and at https://docs.python.org/3/license.html.
- CodeMirror 5: MIT, Marijn Haverbeke and contributors; local license included. Source: https://github.com/codemirror/codemirror5.
- jsPDF: MIT, license included alongside the local library. Source: https://github.com/parallax/jsPDF.
- Raleway: SIL Open Font License, included in `assets/Raleway-OFL.txt`.

No library or media is loaded from a CDN. No externally hosted video is required.

    YOUR A4 PAPER TASK

    Create a flowchart for the same Smart Badge: it displays a welcome icon, waits for Button A, then displays your initials.

    Language help
    A4

    On the A4 paper your teacher gives you

    1. Write the title Smart Badge Flowchart and your name.
    2. Draw these five steps in order: START → DISPLAY welcome icon → INPUT Button A → DISPLAY initials → END.
    3. Use ovals for START/END and parallelograms for inputs/outputs.
    4. Connect every symbol with an arrow.
    5. Compare your drawing with the worked example before taking a photograph.

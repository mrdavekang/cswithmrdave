COUNTDOWN CREW - YEAR 8 MAKECODE ARCADE PROJECT
CS with Mr Dave

START
Open index.html in a modern browser. No build, installation or student account is
needed for this lesson app. GitHub Pages or a school HTTPS web server is preferred.
Keep index.html, styles.css, lesson.js, app.js, report.js, assets and vendor together.
Saving this folder locally does not publish it. No changes to the repository home
page, Git history, GitHub Pages configuration or Teams have been made.

STUDENT ROUTE
Enter a name and class, choose Blocks or Arcade Python, and select language support.
Continue through the cards using the fixed Next button. Back returns one card;
the left-hand stage menu opens visited stages. Go Further appears after Learning
Pit Stop. Its Go to plenary button allows the teacher to end challenge time.
There is no minimum quiz score or keyword-based writing gate. Blank responses
remain unfinished in the report. Opening a card does not prove mastery.

TEACHER TEST ROUTE (do not display these instructions to students)
Enter teacher as the name. A blank class defaults to 8T. Every stage is accessible.
Alternatively use index.html?teacher=1 and select Continue my mission.
Teacher and student responses, backups and evidence use separate storage keys.
Teacher mode is a testing convenience, not a secure authentication system.

LESSON SPINE AND PACING (60 minutes)
Mission briefing 3; Do Now 5; Types of Learning 3; Main Task 1 12;
Main Task 2 20; Learning Pit Stop 3; Go Further 7; Plenary 4; Save/submit 3.
Early finishers can continue challenge missions. Allow more onboarding time for
beginners. Call the class to plenary even if students have unfinished challenges.
Assess: identify counter/condition; perform and test a change; explain stopping.
Accept a short phrase, support-language explanation or spoken demonstration.
Main mission: start 7, pause 500 ms, subtract 1 while countdown > 0, then launch.
No arrays, physical micro:bits, Bluetooth, new artwork or image APIs are required.
Prepared functions provide the scene. Do not make novices edit their grey blocks.
Do not run intentionally endless code. Stop/restart and restore a working version.

MAKECODE TEMPLATES

02 student project: https://makecode.com/_ioxHMeYpd4Wg
03 reactor challenge: https://makecode.com/_2sPdRM1ejWfR
Open a share link and select Edit Code. Then name your local copy.
Keep the same countdown project through both main tasks; the reactor is separate.
Arcade Python is not micro:bit MakeCode Python, MicroPython or desktop Python.
The locally included assets/templates/*.png contain full editable projects. Do
not resize or recompress these cartridge PNGs. Restore via Arcade Home > Import
> Import File. Use the Save control beside the project name for your own backup;
hardware Download is not the same control.
The lesson cannot inspect code in a separate MakeCode tab. Reported test results
and teacher-check requests are self-reports, never forged automatic verification.

VISUAL GUIDES
assets/guides contains actual editor screenshots, captured from these templates.
lesson.js supplies numbered HTML annotations and distinct Blocks/Python views.
Several views reuse the same sharp source image, avoiding duplicate image files.
Do not resize cartridge files to make screenshot guides. Screenshot JPGs are
separate, ordinary images. If replacing a capture, review its annotation geometry
and equivalent text instructions. An image failure leaves written steps usable.
Guide layouts may differ on tablets; check actual school devices before teaching.

LANGUAGE SUPPORT
Mandarin, Korean and Bahasa Melayu support is chosen at entry and changeable in
the header. A contextual instruction translation is visible on each card, with
English preserved. The word glossary has bilingual definitions. Code keywords
remain unchanged. This is task/vocabulary support, not a fully translated editor.
Have a fluent colleague review translations before high-stakes use.

SAVING AND PRIVACY
Lightweight responses, route, language, visited cards and quiz attempts autosave
to localStorage. One student profile is saved per browser; use a backup before
changing student on a shared device. Refresh returns to the entry confirmation;
Continue resumes the exact card rather than restarting the lesson.
Screenshot evidence uses IndexedDB, resized to at most 1600 pixels and JPEG .93.
Only PNG/JPEG/WebP uploads are accepted, up to 8 MB. Evidence remains local; this
app does not upload student work to a server or collect telemetry.
Do not include faces, passwords or private information in screenshots.
Save failures are shown. Use a downloaded backup if browser storage is disabled.
Private browsing, clearing website data or changing browsers can remove progress.

BACKUP / RESTORE / RESET
Work tools > Download lesson backup exports JSON containing name/class, responses,
quiz attempts, progress, language/route and compressed evidence images. This is
separate from your editable MakeCode project PNG. Import confirms replacement,
checks lesson/version and restores evidence. Maximum backup size is 25 MB.
Reset requires confirmation and affects only this lesson in the current mode;
it does not erase other lessons or projects in MakeCode.

PDF AND PRINT
Export PDF works at any stage. The local jsPDF library in vendor produces an A4
report with learning goals, every stage, answers, checked quiz attempts, screenshot
evidence, incomplete work, page numbers and submission reminders. It uses locally
rendered pages so Mandarin/Korean answers can use available browser system fonts.
The PDF is image-based rather than searchable text. JSON preserves editable text.
Filename: Year8_Class_StudentName_Arcade_Countdown_Project.pdf
Work tools > Print / save as PDF is a fallback if direct downloads are blocked.
Browser print settings can add headers/footers; disable those for a clean report.
After PDF export, students get a Teams submission guide and can record that they
selected Turn in. The app cannot verify a download was received or a Teams upload.
The timetable week is deliberately not invented. Tell pupils the exact Classwork
assignment title; update submission wording when the module is created.

HOSTING / LIMITATIONS
For GitHub Pages, publish this repository folder through the existing site setup.
All lesson assets and PDF dependencies are local and use relative paths.
MakeCode links need internet and school-network access. The local visual preview
is illustrative, not a Python interpreter or replacement MakeCode editor.
Local file opening usually works, but some managed browsers restrict file fonts,
IndexedDB, clipboard reading or downloads. HTTPS static hosting is more reliable.
The Paste screenshot button depends on Clipboard API support and permissions.
Ctrl/Cmd+V on the evidence card or Choose screenshot remain alternatives.
Tablet connection workflows are not part of this browser-only Arcade lesson.
No physical iPad was used for QA; responsive tablet-sized browser views were tested.
Automated QA used the local HTTP preview. Direct file opening and native browser
print dialogs were not validated in that preview; check these on school devices.

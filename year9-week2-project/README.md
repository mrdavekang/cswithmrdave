# Year 9 Term 1 Week 2 — Scam Detective

A dependency-free static lesson app for the Year 9 **Scam Detective** project-planning session. It is designed for GitHub Pages and requires no build command. The guided version follows one fictional case from observable clues to a tested computational model.

## Publish with GitHub Pages

1. Upload the **contents of this folder** to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the branch containing these files (usually `main`) and the root folder.
5. Save and wait for the GitHub Pages address to appear.

There is no package installation, server, environment variable, Vite configuration or Vercel configuration.

## Student and teacher access

- Student: open `index.html`, enter a full name and class, then select **Start investigation**.
- Teacher preview: add `?teacher=1` to the page address. This route is not advertised on the student landing page.

Teacher preview uses separate browser storage and unlocks every lesson section.

## Privacy and safety

- Responses remain in the current browser through local storage; they are not sent to a server.
- The lesson uses fictional messages only and instructs students never to open or test suspicious links.
- The planned program estimates concern from observable warning signs. It must not claim that a message is definitely a scam.
- Students should not upload real suspicious messages, passwords or personal information as evidence.

## Evidence and submission

The app records the student's:

- starter retrieval and a six-item clue-sort
- guided user, need and safety-limit decisions
- three safe program requirements and a success criterion
- a five-job decomposition sequence
- a mixed 14-item input–process–output classification challenge with plausible out-of-scope details
- a five-block mini pseudocode build
- a fully annotated pseudocode worked example
- two guided pseudocode reading, prediction and description practices
- a student-written description of the pseudocode they construct
- three additional program-sequencing scenarios in Main Activity 1
- three mini-algorithm repair scenarios in Main Activity 2
- a predicted, animated six-step variable trace
- a structured peer or solo test case
- three interactive level-up experiments
- an unlockable browser-based Python 3 studio with run, stop, reset and `.py` download
- AO1, AO2 and AO3 exit questions

The Python studio unlocks only after the three level-up experiments are correct. It runs locally in the browser and uses prompt boxes for `input()` programs.

The core lesson timings total 60 minutes: 6-minute case-file starter, 8-minute program brief, 12-minute decomposition/IPO activity, 28-minute pseudocode activity and 6-minute plenary. The level-up and Python studio remain optional early-finisher work.

Students can save an optional image, download a JSON progress backup, and create a PDF report for **Microsoft Teams → Week 2 Project**. If direct PDF creation is blocked, the app opens the browser's **Print → Save as PDF** route.

# Year 7 Week 2 Theory — From Problems to Precise Plans

Self-directed 60-minute Computer Science lesson covering decomposition, abstraction, input–process–output, pseudocode, worked examples, flowcharts and peer testing through one clearly defined navigation-instructions project.

## Student use

1. Open the deployed app.
2. Enter a full name and class.
3. Complete the lesson cards in sequence.
4. On the final card, select **Review and export PDF**.
5. In the print window choose **Save as PDF**.
6. Upload the PDF to the Microsoft Teams Assignment **Week 2 Theory**.

Progress is stored only in the current browser and device. Entering the same name and class resumes the same saved profile. The PDF is the evidence delivered to the teacher.

## Teacher review

Enter `teacher` as the name. A class is not required and every lesson card is immediately available. Teacher review data is stored separately from student profiles.

## Evidence and saving

- Text responses, quiz attempts, navigation and interactive clicks are saved locally.
- Up to two optional screenshots can be uploaded or pasted and included in the report.
- The final print-friendly report includes all attempted written responses, the final algorithm, the generated flowchart, screenshots, quiz summary, completion information and the saved interaction record.
- Very large screenshots are resized and compressed before browser storage.

## Images

The eight lesson images are stored in `images`. Each image is used on the relevant concept card. Filenames begin with their lesson sequence number.

## Hosting

This ZIP contains the finished static app. Extract it and upload the complete folder contents to a static host such as a school web server, Netlify, Vercel or GitHub Pages. Keep `index.html`, the `assets` folder and the `images` folder together.

For a quick review, double-click `index.html`. This version is packaged to work directly from the extracted folder as well as from a static web host.

## Browser notes

- Use a current version of Microsoft Edge, Chrome, Firefox or Safari.
- PDF creation uses the browser print dialog. Select **Save as PDF** rather than a physical printer.
- Browser storage is device-local and is not central teacher monitoring.
- Clearing browser data or using another device will not restore an unfinished profile.

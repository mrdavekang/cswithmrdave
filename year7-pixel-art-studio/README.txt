TEACHING MODELS AND CHALLENGES
0 = white; 1 = black. Read left to right, with rows top to bottom.
Row/column numbers in pictures are positions, not denary place values.
Only the starter score question and extra score puzzle use denary conversion.
The six bilingual visual models use a reserved flag and separate example rows.
They are not student mystery or repair solutions.
Main task 1: decode one row, decode an eight-row mystery, repair one mismatch.
There is also a second repair level with two mismatches.
Then investigate the same bits with an opposite colour key, reverse the reading
order and restore it, and rebuild the same 64 bits into 8x8 and 16x4 layouts.
Select the useful picture instructions: dimensions, colour key and reading order.
The opposite key is explicitly restricted to that investigation only.
Main task 2: original icon, eight manually entered rows, reconstruction from
typed bits only, comparison and a short explanation. Keep a version 1 snapshot,
change a feature in version 2, update affected rows and rebuild/test again.
Changing 2–6 pixels is guidance, not a progression rule. Short phrases or oral
explanations are welcome; no explanation keywords are enforced.
The current main icon can be recaptured as version 1 with confirmation, useful
if a pupil explored Improve before finishing the first icon. Both versions,
their binary and checked attempts remain in the JSON backup. PNG export uses
the latest version 2 when it exists, otherwise the original design.
Three guided pixel-data questions cover 64 pixels, 8 bytes and transfer to a
new 8x4 size. These values describe raw one-bit-per-pixel data, not PNG file size.
An invalid row shows question marks rather than copying the original drawing.
Spaces and full-width ０ / １ are accepted. Invalid digits get specific guidance.
Extra challenges: mirror, move right without wrapping, denary-score mystery,
and a separate second original icon that never overwrites the first project.
New extra labs: enlarge 8x8 to 16x16 (four times the pixel count), edit one
large-button quarter to add detail, decode then create a four-colour row with
two bits per pixel, and design within a 20-black-pixel budget. Fewer black
pixels do NOT reduce the fixed raw 8x8 one-bit-per-pixel data: still 64 bits.
The four-colour key is confined to its own lab; the core icon remains one-bit.
Assess recognisability and explanation with human judgement; the app only
checks the representation, reconstruction and supplied puzzle patterns.

SAVING, BACKUPS AND SAFEGUARDING
This version is LOCAL ONLY. It does not connect to Supabase, a teacher dashboard
or any external analytics. The content security policy blocks network requests.
Pictures, code, checked attempts, reflections, hints, progress and interaction
history are saved in localStorage, per normalised name/class, on this browser.
A private per-tab session reference restores the same profile after refresh.
Names are labels, NOT secure identities. Use Change student on shared devices.
Teacher preview uses a separate storage key. No public pupil list is provided.
Storage errors are reported: download a backup rather than assuming a save.
Download backup exports JSON. Restore a backup validates the lesson, picture
dimensions and binary data before asking to replace that local profile.
Reset affects only the current profile and asks for confirmation.
Do not clear browser data or change devices without taking a backup.
Downloaded JSON contains pupil work and identity labels: store it privately.
To add school cloud tracking later, authorise and implement a separate restricted
lesson namespace and teacher access. Do not reuse a theory save label or claim
that this practical is Saved to teacher.

IPAD / LAPTOP CONTROLS
Tap or click pixels; no dragging or screenshots are required.
Tab/arrow keys move through the grid; Space/Enter toggles the focused pixel.
The encoder includes large 0, 1 and Delete buttons plus a numeric input mode.
At tablet portrait widths, the active source row sits directly above the input.
English / English + 中文 is always visible at the top. Vocabulary explanations
and device help are available throughout. The six teaching images themselves
contain both English and Mandarin labels.
Theme choices colour the interface only: the assessed image stays black/white.
The separate four-colour extra lab provides colour exploration with labelled
two-bit pairs. Enlarged resolution grids use 8x8 quarter editors to avoid tiny
16x16 touch targets. Progress has 20 core items; extras are not compulsory.
The WAGBA and keyword strips remain visible while scrolling.
Reduced-motion preferences are respected.

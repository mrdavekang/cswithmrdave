Year 9 Helpdesk Practical - Guided Steps

This is a separate guided route for the original helpdesk practical checkpoint.
The existing whole-class practical is unchanged.

Open index.html, or serve this complete folder with a static web server.
Keep all JavaScript files, assets and vendor files together. The bundled Python
worker supports local file opening as well as HTTP/GitHub Pages hosting.

Students use one file, my_helpdesk.py, throughout. The starting code is already
loaded. Two Main Tasks introduce inputs/calculation/output, then two advice
paths. Each screen has one main action, a matching paper reference and, where
needed, a visible code pattern. Select the line to change highlights the real
editing location; it does not write code for the student. Advancing a step
never replaces the program.

The Python editor has line numbers, automatic indentation, Indent/Dedent,
Undo/Redo, Stop, Download .py and Open saved .py. It has no predictive code
suggestions. input() questions appear in the console while the program runs.
Use Enter or Send to answer one question at a time.

English or English with Mandarin support can be selected. Main text starts at
24 px and code at 22 px; A+ and A- adjust the size. The layout adapts to desktop
and tablet widths. On an iPad, use Safari; downloads are in Files / Downloads.

Progress and code are saved in this browser on this device under the separate
local-storage key year9-helpdesk-guided-v1. Download the .py file to keep or move
the work. No student name is collected and no student work is transmitted.
Start again and Open saved .py both show an on-page replacement confirmation.

The matching English and English-Mandarin papers each have nine pages.
The separate teacher mark scheme retains 40 marks, with support recorded as
independent, supplied reference or prompted. Guided completion is not evidence
of unaided code generation. Teacher answers are kept outside this public app.

Deployment: this folder has been saved locally. It has not been committed,
pushed, published to GitHub Pages or posted to Teams by this task.

Third-party components: Skulpt and its licence are in vendor/. Raleway and
its licence are in assets/. The runtime and editor core are reused from the
existing Year 9 practical checkpoint.

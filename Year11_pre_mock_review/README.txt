LESSON
Read first; Do Now (10 classroom marks); Types of learning; Main Task 1 guided repair; focused reading (8 minutes); Main Task 2 independent original-question routes; Learning Pit Stop; optional paper extension (11 marks); Plenary; ongoing revision record.
Main Task 2 routes: A 10 marks, B 11 marks, C 12 marks. Students choose one route, not all three.
The app includes a two-page reading/activity repair pack for each of the five topics in the printable workbook.
Students can type, extend trace tables, or upload up to three photographs per activity.
Topics not assessed today remain "Not checked" in the skill-level record.

BEFORE CLASS
Print the Do Now (workbook p1), selected repair packs (E pp2-3, N pp4-5, C pp6-7, D pp8-9, P pp10-11), and a few copies of each independent route.
Practice booklet: A pp2-4, B pp5-7, C pp8-10. Extension questions pp2-4.
Keep the two teacher PDFs outside this website. Give out the relevant official marking pages only after independent attempts.
Read the teacher guide's marking cautions, especially the trace-table cap and flowchart arrowheads.
If the trace/flowchart route needs more time, finish fewer parts carefully and carry the rest forward.

SAVING AND TRACKING
Work saves locally in this browser. Private browsing, clearing site data or changing the address can make the old local record unavailable.
Full backup downloads a JSON file with answers, photos and attempt history. Restore after confirmation replaces the current notebook.
Save PDF exports typed work, confidence ratings, original attempt history and paper photographs for Teams.
CSV exports a student's evidence rows for a teacher to combine privately.
Neither PDF, CSV nor backup uploads to Teams automatically. There is no live class dashboard or automatic synchronisation.
Keep first answers and corrections separate. Marking is manual, with official guidance for past-paper work; the app does not grade free-text explanations automatically.
Record score, support and previous exposure before adding an attempt to history. History preserves original snapshots.
Later practices can be logged with source/skill/date/score; repeated exposure must be recorded.
The Plenary skill and practice date also appear as the next check in My revision record.

# Year 7 Binary Explorer

A 60-minute, slide-by-slide computing lesson about data and information, bits and bytes, and four-bit binary using **8, 4, 2, 1**.

## Open the lesson

Public lesson: https://mrdavekang.github.io/cswithmrdave/year7-binary-explorer/

Open `index.html` through GitHub Pages or any static web server. No build step, account, database or paid API is required. All essential scripts, styles, images and the Raleway font are included locally.

## Lesson journey

- Welcome and starting-point checks
- Types of learning: knowledge, skills and understanding
- Main Task 1: school votes, lost property and canteen-order scenarios
- Main Task 2: build, read and repair four-bit binary numbers
- Binary Summit practice game
- Learning Pitstop and plenary
- Binary Arcade: links to further binary games after the plenary

Students answer one question at a time. Feedback and hints help them improve without requiring exact written keywords. English and Mandarin support, touch-friendly controls and visible progress are provided.

Enter `teacher` as the name to preview all lesson pages without a class. Teacher preview has separate local storage; it is not authentication or a teacher monitoring service.

## Saving and privacy

Work is saved in the current browser on the current device. There is no central pupil list or cloud response database. Use **Download backup** to export a JSON backup and restore it when changing browser, device or website address. Browser storage for a local preview does not automatically transfer to the public lesson URL.

Print/PDF is available as an optional backup. No screenshot upload or mandatory PDF submission is needed to complete the lesson. Shared-device users should follow the school's procedures for protecting their saved work.

External game links open separately. The app records link openings locally, not scores or answers from those external websites. Review third-party sites and school filtering before classroom use.

Planning clear route instructions with Python Turtle

WAGBA

Plan and test a First-Day School Tour that takes a new student to several required places in the correct order, then use Python Turtle to draw the route.

Knowledge

  • A journey with several stops can be split into smaller journeys.
  • A useful map keeps the places and route details needed by the student.
  • The First-Day Tour program reads route points in order and draws a line.

Skills

  • Explain who the route is for.
  • Split and plan the journey.
  • Write and test clear instructions.
  • Use coordinates with Python Turtle.

Understanding

Someone who has never visited the school should be able to visit every required stop safely, in the correct order, without guessing.

THE 60-MINUTE ROUTE
0–5     Do Now: helper mission; locate A/B; predict A from real code.
5–10    Knowledge, Skills and Understanding self-checks; choose a focus.
10–20   Main Task 1: open MakeCode; test A; model IPO; predict and test B.
20–30   Main Task 1: change B, test both buttons, explain why A is unchanged.
30–47   Main Task 2: plan two messages, create in MakeCode, test and improve.
47–50   Learning Pitstop, AFTER Main Task 2; choose a useful next step.
50–55   Plenary explanation and exit reflection; oral explanation is allowed.
55–60   Save HEX, print/save report as PDF, and hand in.
Fast finishers: design an LED symbol, make a timed sequence, add an A+B reset.

REAL MAKECODE WORK
Verified starter: https://makecode.microbit.org/#pub:38075-59035-40567-08101
Starter A = Happy; B = Confused. Both event blocks were opened and visually
checked in MakeCode. The included Classroom-Signal-Starter.hex is a fallback.
In MakeCode: Home → Import → Import File to reopen that file.

The lesson app is not an embedded MakeCode editor. Its screenshots are guides,
not live simulators. The large MakeCode button opens the real editor in a separate
tab. Keep it open and return to it rather than repeatedly opening a fresh starter.
If the browser cannot refocus the previous tab, select the existing MakeCode tab
yourself. When resuming at home, import your own saved HEX, not the starter again.

EVIDENCE AND HOME CONTINUATION
PDF = learning report for the teacher. Use the app's Save report as PDF button,
then choose Save as PDF in the browser/system print dialogue. The app cannot
know whether a PDF was actually saved or uploaded.
HEX = real MakeCode project, saved from MakeCode. Hand this in with the PDF.
JSON = this lesson's answers/progress backup; it does NOT contain MakeCode blocks.
Load JSON from the welcome page on another computer. Use Help → Continue alone
if a partner is away. Shared answers and original partner details are preserved.

No pupil screenshots are required. The report records answers, plans, tests,
reflections, skipped steps and the latest 500 activity events. It does not inspect,
grade or capture the external editor. Practical completion is explicitly based on
pupil reports; inspect the HEX and hear the explanation for reliable assessment.

# Year 6 Computing learning checkpoint

Static, one-card-at-a-time assessment for the first three Term 1 lessons. It covers files and folders, clear instructions, algorithms, decomposition, sequence, input/process/output, Scratch coordinates, prediction and debugging. It deliberately does not assess Week 5 selection/repetition, which was not in the study guide.

## Run and publish

- Open `index.html` on a school device, or publish this whole folder at the root of a GitHub Pages repository. Keep the `assets` and `vendor` folders beside it.
- No server, account, build process or network connection is needed for the website itself. The Scratch editor link needs internet; Scratch Desktop can open the downloaded starter offline.
- Test the download, Scratch opening and Teams hand-in process on the actual school devices before the class test.

## Learner journey

The landing page asks for name, typed class and optional English + Mandarin reading support. Cards then open in a fixed order; pupils can go Back, flag an item, or use the review card to revisit an earlier question. Unanswered cards prompt before continuing, but never trap a learner. The on-screen route builder gives physical test feedback, not an answer key.

The practical requires pupils to download the unfinished `.sb3` starter, load and run it in Scratch, record its first result, change a block, test again, and save their own `.sb3` file. The two screenshot guides show only where to find the Motion area and sprite coordinates in a real Scratch interface. They do not contain the solution. Pupils do not need to take screenshots.

The website saves answers in this browser under the learner's name and class. A JSON backup allows continuation on another device. At the end, learners download a PDF of website answers and separately save their Scratch project, then upload **both PDF and `.sb3`** to the Teams assignment. The website cannot submit to Teams on their behalf. It can record an `.sb3` file name, but it cannot inspect or verify the pupil's Scratch code.

For names or answers using Chinese characters, the built-in PDF button asks learners to use **Print / save PDF**, which preserves those characters. The bundled PDF library is local so the ordinary PDF download works offline for Latin-script responses. If the library fails, Print / save PDF remains available.

## Teacher checks

- Confirm the starter opens in the Scratch version used at school and that the sprite x/y fields are visible.
- Confirm browser printing can save a PDF on school devices. Allow pop-ups/new tabs for the Scratch link if necessary.
- Create a Teams assignment that accepts both files; remind pupils to check both attachments before submitting.
- The app records work but does **not** grade free text or verify practical success automatically. Review the PDF and `.sb3` yourself.

The genuine Scratch screenshots are adapted from earlier Year 6 classroom materials. Raleway font is bundled under `assets/OFL.txt`. jsPDF is bundled under `vendor/`.

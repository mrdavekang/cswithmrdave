# Gate Glitch · Save the Robot Expo

A 60-minute Year 6 practice lesson. Open `index.html` directly or serve the
folder with a static host. No sign-in, database, installation, or build step.

Pupils use the supplied faulty HEX in a separate MakeCode tab. The lesson
records their observations; it does not edit or grade the micro:bit program.
The browser stores practice progress locally. A JSON backup restores the
lesson only; a MakeCode HEX saves the program itself. The optional PDF uses the
browser’s Print → Save as PDF. No pupil screenshots or uploads are required.

Run live demonstrations between cards as needed. Main Task 1 is 12 minutes;
Main Task 2 is 22 minutes across its cards. The Learning Pitstop follows Main
Task 2. The separate teacher visual pack contains the corrected reset and
complete model; neither is hosted here.

# Virtual BEETLE:BIT Challenge — GitHub Pages

This folder is a completely static website. It needs no server-side code, database, login or build step.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Open the Pages URL in Chrome or Microsoft Edge.

## micro:bit setup

Download `microbit-controller.js`, paste it into a Microsoft MakeCode micro:bit project using JavaScript view, and flash it to the micro:bit. Connect with a USB data cable, open the GitHub Pages site, select **Connect micro:bit**, then hold the controller level and press A+B.

This is a school learning prototype and is not official Cytron software.

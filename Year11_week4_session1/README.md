# Year 11 • Term 1 Week 4 Session 1

## Start
Open `index.html` in Edge or Chrome. All fonts, scripts and the original exam image are included. There is no installation or build step. The complete folder is suitable for GitHub Pages.

Students enter their name and class. Enter `teacher` as the name, leaving class blank, to use a separate teacher-preview profile. There is no visible teacher option. All lesson stages are freely navigable, including in student mode; this avoids locking pupils out of needed reading. Teacher preview is a convenience, not authentication and not a secure store for answers.

## Lesson
5 min Do Now → 3 min Types of Learning → 18 min Main Activity 1 → 22 min Main Activity 2 → 4 min Pitstop → 5 min Plenary → 3 min export. Optional extension uses available independent-work time or later practice; it does not add to the 60 minutes.

Six matched Knowledge / Skills / Understanding checks are revisited. Each phase gives a topic-specific next action. Unknown and not attempted are not scores. There is no calculated mastery percentage or live teacher dashboard. If help is needed, pupils must speak to the teacher or show their screen.

Main Activity 2: 10 classroom marks. Extension: 4 original November 2024 exam marks, followed by 6 separately labelled classroom challenge marks. A photograph of paper answers can replace typing. Formative partner-check explanations are intentionally visible after a learner chooses to reveal them; these are not the official mark scheme.

## Work and privacy
Names, responses, photos and feedback are stored in IndexedDB in the current browser under separate name/class profiles. On file URLs, browser behaviour can vary. Watch the save status; do not assume work is saved if an error is displayed. Renaming or moving the folder can change access to local saved work. Browser clearing/private sessions can remove it.

Save a JSON backup before switching browser, device or folder. Use “Open a saved lesson backup” on the landing page to restore. Restore asks before replacing the named profile. PDF and JSON exports contain pupil information; keep them private and never upload them into the public repository. No learner work is sent to a server by the app.

The PDF button directly downloads an A4 report with all answers, learning checks, next actions, feedback snapshots and photographs at their original aspect ratios. It does not automatically submit to Teams. Students must open/check the PDF and upload it themselves.

Photos: JPEG, PNG and WebP; max 15 MB per original; resized to a maximum 2000 px. Choose multiple files or paste copied images on a task page. Add captions and check legibility. HEIC/DNG must be converted by the device first.

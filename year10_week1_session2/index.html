Quick guide: Python arithmetic operators

Python uses symbols to tell the computer which calculation to perform. The symbols are similar to mathematics, but multiplication uses * rather than ×.

Python operatorMeaningExampleResult
+addition7 + 310
-subtraction7 - 34
*multiplication7 * 321
/division7 / 23.5
Operator needed today The calculator awards 5 points for every correct answer, so it uses multiplication: correct_answers * points_per_answer.

Why is int() provided? Python normally receives keyboard input as text. int() converts whole-number input so it can be used in a calculation. You may copy this pattern today.

Challenge 1 · Bonus points upgradeUse + and *

Your task: Your course-points calculator awards 5 points for every correct answer. Extend it so that it also awards 2 points for every bonus task completed.

Your program must: ask for the number of correct answers and bonus tasks, calculate both sets of points, add them together and display the final score.

Python calculation to build: final_score = (correct_answers * 5) + (bonus_tasks * 2)

Example run
Correct answers: 4
Bonus tasks: 2
Final score: 24 points

Test your program: Before running it, predict the result for 3 correct answers and 4 bonus tasks. The program should display Final score: 23 points.

Challenge 2 · Times threeUse *

Your task: Create a program that asks the user for one whole number and calculates three times that number.

Your program must: store the input as an integer, multiply it by 3 and display the original number and the result in a complete sentence.

Python calculation to build: result = number * 3

Example run
Enter a number: 7
7 times 3 is 21

Test your program: Try 0 and then 9. The results should be 0 and 27.

Challenge 3 · Add two scoresUse +

Your task: Create a score calculator that combines the points earned in two rounds of a competition.

Your program must: ask for two whole-number scores, store them using meaningful variable names, add them together and display the total score.

Python calculation to build: total_score = first_score + second_score

Example run
First score: 12
Second score: 8
Total score: 20

Test your program: Before running it, predict the total for scores of 25 and 17. The program should display Total score: 42.

Challenge 4 · Points remainingUse -

Your task: A student is working towards a points target. Create a program that tells the student how many more points are needed.

Your program must: ask for the target and the points already earned, subtract the earned points from the target and display the points remaining.

Python calculation to build: points_remaining = target_points - points_earned

Example run
Target points: 20
Points earned: 13
Points remaining: 7

Test your program: Use a target of 50 with 32 points already earned. The program should display Points remaining: 18.

Challenge 5 · Study minutesUse *

Your task: A student studies for the same number of minutes on each of five school days. Create a program that calculates the weekly total.

Your program must: ask for the minutes studied per day, multiply this value by 5 and display the total number of study minutes.

Python calculation to build: weekly_minutes = minutes_per_day * 5

Example run
Minutes per day: 25
Minutes in five days: 125

Test your program: Enter 40 minutes per day. The program should display Minutes in five days: 200.

Challenge 6 · Seconds in a lessonUse *

Your task: Create a time converter that changes the length of a lesson from minutes into seconds.

Your program must: ask for the lesson length in whole minutes, multiply it by 60 and display the equivalent number of seconds.

Python calculation to build: seconds = minutes * 60

Example run
Lesson length in minutes: 60
Seconds in the lesson: 3600

Test your program: Enter a lesson length of 45 minutes. The program should display Seconds in the lesson: 2700.

Challenge 7 · Total shop costUse *

Your task: A school shop sells notebooks at the same price. Create a program that calculates the total cost of several notebooks.

Your program must: ask for the whole-number price of one notebook and the number being purchased, multiply the two values and display the total cost. Use whole-number prices for this exercise.

Python calculation to build: total_cost = notebook_price * number_of_notebooks

Example run
Price of one notebook: 6
Number of notebooks: 4
Total cost: 24

Test your program: Use a price of 9 and a quantity of 7. The program should display Total cost: 63.

Challenge 8 · Mean of two scoresUse +, / and brackets

Your task: Create a program that calculates the mean score from two rounds of an assessment.

Your program must: ask for two whole-number scores, add them together, divide the total by 2 and display the mean. Use brackets so that Python completes the addition first.

Python calculation to build: mean = (first_score + second_score) / 2

Example run
First score: 14
Second score: 18
Mean score: 16.0

Test your program: Use scores of 9 and 15. The program should display Mean score: 12.0.

Challenge 9 · Complete teams and leftoversUse // and %

Your task: A teacher needs to divide a class into equal-sized teams. Create a program that reports the number of complete teams and the students left over.

Your program must: ask for the total number of students and the number of students in each team. Use // to calculate the complete teams and % to calculate the remainder. Use a team size greater than zero. Do not use selection or loops.

Python calculations to build: complete_teams = students // team_size
students_left_over = students % team_size

Example run
Number of students: 23
Students per team: 4
Complete teams: 5
Students left over: 3

Test your program: Enter 31 students with 6 students per team. The program should display 5 complete teams and 1 student left over.

Challenge 10 · Square a numberUse **

Your task: Create a program that calculates the square of a whole number. Squaring means multiplying a number by itself.

Your program must: ask for one whole number, use the Python power operator ** to square it and display the original number and result in a complete sentence.

Python calculation to build: result = number ** 2

Example run
Enter a number: 7
7 squared is 49

Test your program: Try 0 and then 12. The results should be 0 and 144.

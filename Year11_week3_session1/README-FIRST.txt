YEAR 11 - WEEK 3 SESSION 1: NETWORK TOPOLOGIES
Redesigned 8 September 2026

OPEN THE LESSON
Open index.html, or place the contents of this folder in your GitHub Pages lesson folder.
Keep assets/, resources/ and vendor/ beside index.html. No build step, account service or external hosting platform is needed. All paths are relative, including the printable resources and local fonts.

STUDENT WORK
Enter name and class. The same name and class on the same browser reopens that pupil's work. Different names/classes have separate local records. This is a convenience, not secure authentication. Do not leave confidential work open on shared devices.
Text, drawings, photographs and feedback are saved on that device using browser storage. Nothing is sent to a teacher automatically. Students download their evidence PDF and submit it in Teams.
Use Save editable backup on My evidence before changing device/browser or clearing browser data. Import that file to continue. If saving fails, the lesson displays a warning and will not silently discard the open work through Close my work.
Photographs: JPG, PNG or WebP; six per stage; 12 MB per original image. Images are resized locally for storage. HEIC/DNG files must be exported to JPG first.

TEACHER REVIEW
Enter teacher in the name box; leave class blank. All stages can be shown at once. There is no visible teacher selector on the student landing page.
This mode is NOT a password-protected area. It does not contain the official mark scheme, classroom answer pack or a live class dashboard. The separate teacher folder supplied with this lesson must stay OUTSIDE your public GitHub Pages folder.
Show my work opens the current student's responses for face-to-face feedback. The student records the feedback they received and a separate improvement. These are student-recorded notes, not verified teacher marks.

LESSON
Do Now -> Types of Learning -> Main Task 1 -> Main Task 2 -> Learning Pitstop -> Plenary -> PDF / Teams.
Optional: original exam practice (14 marks), or fault investigation (10 marks). Do not require both in the same 60-minute lesson.
Navigation is not locked. Students can return to reading or attend the plenary with unfinished work. Attempted status is not a mastery grade. Blank marks remain blank; zero is a valid recorded score.
The old v1 browser record is left untouched. A matching student can download that record if present. The redesigned tasks have a separate v2 record.

PRINTING
worksheet.html has the four core lesson pages and one optional fault-investigation page. Print A4 at 100%, without browser headers/footers. The original 14-mark question paper is a separate four-page PDF in resources/; its original page numbers remain visible.
Student evidence is downloaded directly as a paginated PDF with embedded Raleway font. Check photographs before submitting. Save an editable backup as well if continuing later.

READING
Textbook printed pp. 230-231 is included. The app visibly corrects the book's terminator error and its overly absolute star-performance claim. Read the correction before using the original pages. The fuller app reading is a lesson explanation, not a verbatim textbook quotation.

PUBLISHING
Upload only this site folder's contents. Do not upload the separate teacher folder, backups of student work, or any completed pupil PDF.
No automatic Git commit, push or deployment is performed by opening this folder.

FILES
index.html / lesson.js / app.js / styles.css: lesson and interactions.
worksheet.html: printable paper route.
resources/: original textbook extract and original exam practice PDF.
assets/exams/: original question-paper screenshots.
assets/images/: previously prepared teaching visuals.
assets/fonts/: Raleway and offline PDF font data.
vendor/jspdf.umd.min.js: local PDF generation library, retaining its licence header.

YEAR 11 NETWORK TOPOLOGIES WEB APP
Term 1 · Week 3 · Session 1

WHAT IS INCLUDED
- Student landing page for name and class
- Sequential lesson sections with local progress saving
- Hidden teacher review access
- Starter, learning readings, two main activities, extension and plenary
- Six purpose-built topology images
- Mouse, touch and trackpad drawing canvases
- Self-marking, corrections and mark-reclaim prompts
- Printable student evidence report for Microsoft Teams submission
- Raleway font bundled locally

TEACHER REVIEW ACCESS
There is no teacher-mode button on the student screen.
Enter the word teacher in the Full name box. The class box may be left blank.
All pages and answer materials will be unlocked for review.

STUDENT DATA
Responses and drawings are stored only in the browser's local storage.
The website does not send or upload student data anywhere.
Clearing browser storage or selecting Reset all progress removes the saved work.

PDF EVIDENCE REPORT
At the end of the lesson, select Export / Save as PDF.
In the browser print window, select Save as PDF.
Students then upload the saved PDF to the relevant Microsoft Teams assignment.

GITHUB PAGES DEPLOYMENT
1. Create a new GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. In GitHub, open Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and the /(root) folder, then save.
6. Keep the assets folder structure unchanged.

The app is entirely static. It needs no database, server, Vercel account or API key.

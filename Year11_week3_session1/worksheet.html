Do Now: what makes a network?

Name:Class:Date:
Read first

A network connects devices so that they can communicate and share resources. LAN describes a network's geographical scope. Copper cable, fibre-optic cable and wireless connections describe how data travels. Today we will investigate how the devices and their connections are arranged.

1. A school connects computers and a shared printer within one building. Is this a LAN or WAN? Explain your choice.

2. Give one benefit of sharing a printer through a network.

3. Name one wired transmission medium.

4. Two networks contain the same number of computers. Could the way they are connected affect what happens when a cable breaks? Make a prediction.

Types of Learning

Knowledge: remember the parts. Skills: draw and check the connections. Understanding: follow the path and explain a fault.

OPTIONAL FAULT INVESTIGATION · 10 MARKS

The computers work. The files do not.

Name: ____________________________________

The media lab now uses a star network. All computers can communicate with one another and use the shared network printer. Nobody can open files stored on the file server.

A student concludes: “The central switch must have failed.”

The file server provides shared files and has its own network connection. A device, its connection or its service can fail without every other connection failing.

1. Explain why the observations do not support this conclusion. [2]

2. Suggest two possible causes consistent with the observations. [2]

3. Describe a check for each cause and explain what each result could tell you. [4]

4. Explain the difference between losing one shared service and losing communication across the whole network. [2]

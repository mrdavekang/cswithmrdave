How to use this guide

Each Bronze question is testing whether you can combine a few basic Python building blocks. This guide has two halves:

  1. Python topic library — short tutorial-style explanations with example syntax, the same way you'd read a textbook. The examples are generic; they are not solutions to the competition questions.
  2. Hint map — for each question, a list of the topics that are most likely to be useful. Click a topic pill to jump to its explanation.
Remember the rules: you may use this reference, but you must write your own code. No AI tools are allowed. This page only reminds you what Python can do — working out how to combine it is the challenge.

Python topic library

Variables & numbers

A variable stores a value so you can use it later. Python has whole numbers (int), decimals (float), and text (str).

count = 0          # an integer
average = 2.5      # a float (decimal)
name = "Scout"     # a string
count = count + 1  # update a variable
A very common pattern is a counter (start at 0, add 1 when something is true) or an accumulator (build up a running total).

The remainder trick: n % 2 == 0 is True when n is even. More generally, n % k == 0 is True when n divides exactly by k.

Strings

A string is text. You can measure it, change its case, search it, slice it and split it.

s = "Hello World"
len(s)            # 11  (number of characters)
s.lower()         # 'hello world'
s.upper()         # 'HELLO WORLD'
s.replace(" ", "")# 'HelloWorld' (remove spaces)
s[0]              # 'H'  (first character, index 0)
s[::-1]           # 'dlroW olleH' (reversed)
s.split(" ")      # ['Hello', 'World'] -> a list of words
" ".join(words)   # join a list of words back into one string
"ll" in s         # True  (is it a substring?)
s.find("World")   # 6   (index where it starts, or -1 if absent)
Slicing: s[start:stop] takes part of a string. s[::-1] is a famous way to reverse one. Indexes start at 0.

Lists

A list holds many values in order. Most Bronze questions hand you a list.

nums = [3, 6, 8, 2, 5]
len(nums)        # 5
nums[0]          # 3  (first item)
nums[-1]         # 5  (last item)
nums[1:3]        # [6, 8]  (a slice)
for x in nums:   # visit every item
    print(x)
nums.count(6)    # how many times 6 appears

A list can also hold lists — handy for coordinates like [[0,1],[1,3]]:

points = [[0, 1], [1, 3]]
for p in points:
    x = p[0]
    y = p[1]

Loops

Loops repeat an action for every item, or a fixed number of times.

# Loop over each value
for x in nums:
    ...

# Loop over positions (indexes) 0,1,2,...
for i in range(len(nums)):
    current = nums[i]

# Look at an item AND its neighbours
for i in range(1, len(nums) - 1):
    left  = nums[i - 1]
    right = nums[i + 1]
When a question talks about an item's neighbours, or the value before/after it, you usually need the index version with range.

If statements & booleans

if x > 5:
    count = count + 1
elif x == 5:
    ...
else:
    ...

# combine conditions
if x > left and x > right:
    ...
if x > 0 or x == target:
    ...
and needs both sides true; or needs at least one. Use these when a question says "greater than both…" or "positive or zero".

Sorting

sorted(nums)              # new list, smallest first
sorted(nums, reverse=True)# largest first
nums.sort()               # sorts the list in place
Sorting helps when you care about middle values, the largest few, or putting things in order before comparing.

Sets (unique items)

A set automatically throws away duplicates.

ids = [1, 3, 2, 2, 3, 4]
unique = set(ids)   # {1, 2, 3, 4}
len(unique)         # how many different values

Dictionaries (counting how often things appear)

A dictionary stores key → value pairs. A classic use is tallying how many times each value shows up.

tally = {}
for x in items:
    if x in tally:
        tally[x] = tally[x] + 1
    else:
        tally[x] = 1
# now tally[x] is how often x appeared
Also useful: list.count(value) tells you how many times a single value appears in a list.

Maths & formulas

Python is a calculator. You can rearrange a formula on paper, then translate it into code.

y = 2 * x + 1        # substitute a value into an equation
dist_sq = x**2 + y**2# squared distance from the origin
value = a * (1 - r) ** n   # powers with **
Tip for "given the answer, find the input" questions: these are algebra. Rearrange the formula by hand first (get the unknown on its own), then code that rearranged version. Watch whether the result should be an int or round()ed.

Main Task 2 · Build · 18 minutes

Build the Rescue Rover status controller.

Work in pairs: the Driver places blocks; the Navigator reads the requirement and checks the event. Swap after two events.

Finding and fitting the blocks INPUT gives you the event container: on button A pressed. BASIC gives you the action block: show arrow or show icon. The action block fits inside the event because it tells the micro:bit what to do when that event happens.

OPEN LOCALLY
1. Open index.html in a modern browser.
2. Enter the student's name and class.
3. Work saves in that browser on that device.
4. Export the PDF from the final page and submit it to Teams.

TEACHER REVIEW
Enter teacher in either the name or class field.
There is no visible teacher-mode option on the landing page.
Teacher review opens all lesson pages in one continuous view.

GITHUB PAGES
1. Upload every item in this folder to the root of a GitHub repository.
2. Keep the assets, resources and vendor folders unchanged.
3. In repository Settings > Pages, publish from the main branch and root folder.
4. The site does not require a build command or external hosting service.

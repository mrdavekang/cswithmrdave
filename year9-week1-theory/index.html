Key Topic
Year 9 Computer Science readiness
WAGBA
Demonstrate what we already know about algorithms and Python, and establish the routines needed to work successfully in Year 9 Computer Science.
Knowledge
Know the difference between an algorithm, a program and source code; recognise IPO and AO1–AO3; know expectations for code, files and evidence.
Skills
Trace and debug short Python programs, use technical vocabulary, organise files correctly and reflect on current strengths.
Understanding
Understand that successful programming involves planning, testing, debugging, explaining and improving—not simply making code run.

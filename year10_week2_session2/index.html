Names, values and data types

Read the short recap first. Then answer five questions, working from top to bottom. You can look back at the recap or ask for help at any time.

Allow about 7 minutes, including the reading. This is practice, not a timed test.

Read first: the words you will use

1. The name and the value are different

A game needs to remember a player's score. This Python line stores it:

player_score = 12
Identifier
The name used in code: player_score.
Value
The data stored under that name: 12.
Assignment
= stores the value on the right under the name on the left.

2. A data type describes the kind of value

OxfordAQA uses general terms; Python uses its own names:

  • 12 — integer / int: a whole number.
  • 12.5 — real / float: a number that can include a fractional part.
  • "Maya" — string / str: text. Quotes make a string literal, even when the text contains digits.
  • True — Boolean / bool: one of two logical values, True or False.

A character is one text symbol. Python stores "A" as a one-character str, with no separate character type.

3. Choose a name that explains its purpose

remaining_lives tells a reader more than n. Meaningful names help you understand, check and change a program later.

For today's names, use letters, digits and underscores (_), but never start with a digit. Do not use spaces, hyphens or Python keywords such as if. Python allows an underscore at the start; we will practise starting with a letter.

4. A variable's value can change

If lives = 3 is followed by lives = 2, the name stays lives but its value becomes 2. This is reassignment. print(lives) then displays its current value.

Reading: named storage

A variable is a named storage location whose value can change while a program runs. An assignment statement stores a value using =. In Python, the first assignment creates the variable; a later assignment can replace its stored value.

A constant is a named value that should not change while the program runs. Python does not enforce constants, so programmers use UPPERCASE_SNAKE_CASE to communicate “do not change this”. Variables normally use lowercase_snake_case.

Use meaningful identifiers with letters, digits and underscores, but no spaces or hyphens. Do not start with a digit or use a Python keyword such as if. For this lesson, practise starting with a letter; Python also permits an underscore at the start.

Worked example

player_score = 12
Identifierplayer_score
Stored value12
Data typeInteger / int
RoleVariable, because the score may change
The decision modelIf the name represents a fixed rule or setting that should remain unchanged, use a constant. If it represents user data, a result, or changing program state, use a variable. The current value alone does not decide the role.

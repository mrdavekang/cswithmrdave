# Week 2 Session 2 — Variables and Constants

Open `index.html` directly, or upload this entire folder to a GitHub Pages repository.

## Teacher preview

Enter `teacher` as the name. The class field can be left blank. Teacher preview data is saved separately from student data.

## Student evidence

- Written answers and pasted code autosave in the browser.
- Screenshot evidence is stored in the browser's local database.
- The **Export complete PDF** button prepares every section and opens the print window. Choose **Save as PDF**.
- Students should keep using the same device and browser until they have exported and submitted their work.

No Python code runs inside the webpage. Students copy the supplied code into their own Python IDE.
